# SmartDoc — Public Service & Digital Document Management System

SmartDoc is a centralized **Document Creation, Updation & Management Information System**.

Urban residents frequently need to create, update, or renew vital documents such as **Aadhaar Card, PAN Card, Indian Passport, Driving Licence, Voter ID (EPIC), and Birth Certificate**. SmartDoc simplifies discovery, provides comprehensive prerequisite checklists, prevents users from falling victim to clone/phishing sites by linking directly to authentic sovereign portals, and provides a structured personal document vault.

---

## 🚀 Key Features (Phase 1)

- **SmartDoc Design System**: Built with modern Dark Navy (`#0B132B`) and Bright Blue (`#2563EB`) visual hierarchy.
- **Document Services Directory**: Full-text search with real-time keyword matching and category filters (*Identity, Financial, Travel, Transport, Civic, Certificates*).
- **Comprehensive Document Profiles**: Detailed overviews with issuing authorities, turnaround estimates, fee brackets, and primary real-world uses.
- **22+ Verified Public Services**: Step-by-step application walkthroughs and mandatory supporting document checklists (PoI, PoA, DoB, biometrics).
- **Verified Sovereign Portals**: Direct, official portals (UIDAI, Income Tax e-Filing, Passport Seva, Sarathi Parivahan, ECI, CRS) with cybersecurity guidance and legal non-affiliation notices.
- **User Dashboard & Vault Preview**: Roadmap preview for personal document storage, categorization, and expiration alerts.

## 🏁 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Raccoon-UX/SmartDoc.git
cd SmartDoc
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
