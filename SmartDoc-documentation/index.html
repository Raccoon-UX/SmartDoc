01. Getting Started / Overview

SmartDoc Overview

A centralized public service discovery platform combined with a private, encrypted digital document vault.

● IMPLEMENTED React 18 Vite 6 PostgreSQL RLS Supabase S3

SmartDoc is a unified web platform designed to eliminate administrative friction in civic documentation across India. It provides a structured, searchable catalog of 34+ sovereign public document services alongside an isolated, private vault where citizens can store, preview, and organize copies of their personal identity records.

Key Architectural Takeaway

SmartDoc does not act as an unverified broker. Citizens are guided through prerequisite checklists, fee structures, and turnaround timelines before being securely redirected directly to audited, sovereign government portals (.gov.in / .nic.in).

Service Discovery Engine

Authentication & Account Management

Supabase Auth with JWT session persistence, trigger-based profile sync, and password recovery.

MODULE SD-07: Authentication & Account
JWT Auth State
Routes: /login, /register, /forgot-password, /reset-password
TypeScript — AuthContext State Listener 
// Initial session retrieval
supabase.auth.getSession().then(({ data: { session } }) => {
  setSession(session);
  if (session?.user) {
    fetchProfile(session.user.id, session.user.email || '');
  }
  setIsLoading(false);
});

// Real-time Auth State Change Listener
supabase.auth.onAuthStateChange((_event, newSession) => {
  setSession(newSession);
  if (newSession?.user) {
    fetchProfile(newSession.user.id, newSession.user.email || '');
  } else {
    setUser(null);
  }
});

09. Engineering / Upload Pipeline

Document Upload Pipeline

Validation, sanitization, S3 streaming, and atomic PostgreSQL metadata rollback.

1
File Validation: Client checks file size (≤ 10MB) and allowed MIME types (application/pdf, image/jpeg, image/png).
2
UUID Scoping: Generates secure path <userId>/<docId>/<sanitizedName>.
3
Storage Upload: Streams binary to private S3 bucket user-documents with user-isolated RLS.
4
Atomic DB Rollback: Inserts record in PostgreSQL documents table. If DB fails, the uploaded storage file is immediately deleted.

Database Entities & Storage Schema

PostgreSQL tables, foreign key constraints, indexes, and storage bucket definitions.

SQL — Schema Definition (01_phase3_init.sql) 
-- 1. Profiles Table
CREATE TABLE public.profiles (
  id UUID REFERENCES auth.users(id) ON DELETE CASCADE PRIMARY KEY,
  full_name TEXT,
  email TEXT,
  avatar_url TEXT,
  created_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now()) NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now()) NOT NULL

-- 2. Documents Table
CREATE TABLE public.documents (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
  name TEXT NOT NULL,
  category TEXT NOT NULL DEFAULT 'other',
  document_type TEXT NOT NULL DEFAULT 'pdf',
  description TEXT,
  file_path TEXT NOT NULL,
  file_name TEXT NOT NULL,
  file_size BIGINT NOT NULL DEFAULT 0,
  mime_type TEXT NOT NULL,
  issue_date DATE,
  expiry_date DATE,
  issuing_authority TEXT,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now()) NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now()) NOT NULL
);

16. Engineering / Security

Row Level Security (RLS) & Policies

Server-enforced user isolation preventing cross-tenant data leakage.

  • auth.uid() = user_id on public.documents for SELECT, INSERT, UPDATE, DELETE.
  • auth.uid() = id on public.profiles for SELECT, INSERT, UPDATE.
  • (storage.foldername(name))[1] = auth.uid()::text on storage.objects for S3 folder isolation.
  • Short-lived signed URLs (expiresInSeconds: 300) for in-browser file previews.

25. Quality / Limitations

Known Project Limitations

Transparent documentation of current phase engineering boundaries.

  • Static Catalog Curation: Service entries are curated in TypeScript data structures rather than polled live from government REST APIs.
  • Client-Side Catalog Search: Full-text search runs in-browser, optimal for current catalog size (34+ entries).
  • Raw Binary Storage: Uploaded images and PDFs are stored without native automated OCR text extraction.

32. Reference / FAQ

Engineering FAQ

Common questions regarding architecture, security, and storage.

Is SmartDoc an official government portal?

No. SmartDoc is an independent discovery platform and encrypted personal document vault that guides citizens to authentic sovereign portals.

Where are uploaded documents stored?

All user documents are stored in private non-public S3 buckets protected by Row Level Security (RLS) policies scoped strictly to the authenticated user ID.
